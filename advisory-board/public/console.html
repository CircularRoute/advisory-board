Advisory Board

Board Console

Convene a multi-vendor board on any hard question: pick the tier and seats, see the cost before you commit, press Run. Not tied to any project or dataset. Every run spends real API credit; the real cost is printed with the answer.

Configuration

Board tier
Default to mid; use --compare (or the buttons below) to learn where top actually changes the answer for your questions.
Seats
A seat may sit at a different tier than the board - e.g. a top board with a mid Gemini.
Default: a non-sitting Anthropic model from another tier. If a mixed board seats the default chair, it walks tiers automatically.
Tier comparison
Never convene the board on a question a single model would answer just as well.
