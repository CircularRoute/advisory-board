Advisory Board

One hard question.
Three independent minds.

Frontier models from Anthropic, OpenAI and Google answer independently, blind-review each other, and a chairman distills one answer that names where they disagreed. You see the cost before you commit; the real cost is printed with the answer.

Configuration

Board tier
Default to mid; use Calibrate below to learn where top actually changes the answer for your questions.
Seats
A seat may sit at a different tier than the board - e.g. a top board with a mid Gemini.
Default: a non-sitting Anthropic model from another tier. If a mixed board seats the default chair, it walks tiers automatically.
Calibrate
Calibrate runs the same question past two or three boards at different capability tiers and reports, side by side, whether the pricier board actually reached a different conclusion — or only cost more. Use it occasionally to learn which tier your kind of question needs. Cost multiplies by the number of tiers.
Never convene the board on a question a single model would answer just as well.
